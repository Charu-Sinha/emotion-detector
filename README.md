# 🧠 NeuraSense — Facial Emotion Detector

A real-time AI-powered facial emotion detection web app built with face-api.js.
No backend, no installation — runs entirely in the browser.

## 🔗 Live Demo
👉 https://Charu-Sinha.github.io/emotion-detector

## 📸 Preview
![NeuraSense Emotion Detector](screenshot.png)

## ✨ Features
- 🖼️ Upload any image and detect emotions instantly
- 📷 Real-time live camera detection at 10–20 FPS
- 😄 Detects 7 emotions: Happy, Sad, Angry, Fearful, Disgusted, Surprised, Neutral
- 👥 Supports multiple faces simultaneously
- 📊 Shows confidence percentage for each emotion
- 🕒 Detection history log

## 🛠️ Tech Stack
- HTML, CSS, JavaScript (zero frameworks)
- face-api.js — browser-based deep learning
- Deployed on GitHub Pages

## 🚀 Run Locally
```bash
python -m http.server 8080
```
